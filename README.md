# Timex Solution Inc — New Website

This is a from-scratch static website intended to become the new Timex Solution Inc homepage.

## Deploy to Vercel
Upload the contents of this folder to the repository root:

- `index.html`
- `vercel.json`
- `robots.txt`
- `assets/poster.jpg`
- `assets/timex-journey.mp4`

Use Vercel Framework Preset **Other**. No build command is required.

## Animation
The scroll journey uses one H.264 MP4 generated from the supplied 236 frames. It is served from `/assets/timex-journey.mp4` and scrubbed according to scroll progress.
